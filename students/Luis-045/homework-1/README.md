# Personal Portfolio

This project is a simple personal portfolio website created as part of Homework 1 for the Git Fundamentals module.

## Project Description

The purpose of this project is to practice a complete Git and GitHub workflow while developing a basic portfolio website.

The portfolio will include information about me, my projects, and contact information.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Current Structure

The project currently contains the initial HTML structure and the main sections of the portfolio.

## Git Workflow

For this project, I used a feature-branch workflow.

The main homework branch is:

`feat/Luis-045/homework-1`

Feature branches created:

- `feature/Luis-045/initial-structure`
- `feature/Luis-045/add-styling`
- `feature/Luis-045/add-content`

Each feature was developed in its own branch and integrated using Pull Requests.

## Commit Convention

Commit messages follow this format:

`<type>: <short description>`

Examples:

- `feat: add about me content`
- `style: improve navigation styling`
- `docs: add initial project README`

## Setup Instructions

1. Clone the repository.
2. Navigate to `students/Luis-045/homework-1/`.
3. Open `index.html` in a web browser.

No additional dependencies are required.
