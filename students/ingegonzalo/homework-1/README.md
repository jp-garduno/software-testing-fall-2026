# git-workflow-practice
# Personal Portfolio

## Description

A simple personal portfolio website created to practice Git and GitHub workflows.

## Technologies Used

* HTML
* Bootstrap
* CSS
* Git
* GitHub

## Git Workflow

### Branching Strategy

The project was developed using feature branches created from `main`.

Branches used:

* `feature/initial-structure`
* `feature/add-styling`
* `feature/add-content`

### Commit Convention

* `feat:` New features
* `style:` Styling changes

## Setup

```bash
git clone https://github.com/ingegonzalo/git-workflow-practice.git
cd git-workflow-practice
```

Open `layout/index.html` in a browser.

## Lessons Learned

This project helped me practice creating branches, making meaningful commits, opening pull requests, and merging changes into the main branch.
