# My Portfolio

A simple personal portfolio website created to practice Git and GitHub workflows.

## Technologies Used

- HTML
- CSS
- JavaScript

## Git Workflow

This project was developed using feature branches. Each feature was developed separately and then merged into the `main` branch through a pull request.

### Branches

- `feature/initial-structure` - Created the basic HTML structure and navigation.
- `feature/add-styling` - Added CSS styling to the website.
- `feature/add-content` - Added personal information, projects, JavaScript interaction, and footer.

### Commit Convention

Commits use the following format:

`type: short description`

Examples:

- `feat: add navigation menu`
- `style: improve text formatting`

The main commit types used in this project are:

- `feat` - New features
- `fix` - Bug fixes
- `style` - Formatting and styling changes
- `docs` - Documentation changes

## Setup

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional dependencies are required.

## Lessons Learned

This project helped me practice creating branches, making meaningful commits, pushing changes to GitHub, creating pull requests, and merging changes into the main branch.
