Descripción del proyecto

Este es un sitio web de portafolio personal simple, creado como parte de la Tarea 1 del curso, con el objetivo de practicar el flujo de trabajo completo de Git y GitHub (ramas, commits y pull requests).

El sitio incluye:

Sección de inicio
Sección "Sobre mí"
Sección de proyectos
Sección de contacto
Tecnologías utilizadas
HTML5
CSS3
Git / GitHub
Estrategia de Git Workflow

Para este proyecto usé un flujo de trabajo basado en ramas de funcionalidad (feature branches), donde cada rama se enfocó en una parte específica del proyecto:

Ramas creadas
Rama Propósito
feature/initial-structure Creación de la estructura básica en HTML y el archivo .gitignore
feature/add-styling Estilos con CSS, incluyendo diseño responsivo para móvil
feature/add-content Contenido real: biografía e información de contacto

Cada rama se creó a partir de main, se trabajó de forma independiente, y al finalizar se integró mediante un Pull Request revisado y fusionado en GitHub.

Convención de mensajes de commit

Seguí el formato <tipo>: <descripción corta>, usando los siguientes tipos:

feat: — nueva funcionalidad o contenido
style: — cambios de estilo/formato, sin afectar la lógica
docs: — cambios en documentación

Ejemplos de commits reales del proyecto:

feat: add basic HTML structure
docs: add gitignore file
style: add base CSS styling
style: add responsive layout for mobile
feat: add personal bio content
feat: add contact information
docs: update README and add reflection
