## 4. Key findings

- Browser start-up: **Playwright** is faster (1,745 ms vs 868 ms on average).
- Largest gap between tools: **Delete 1 todo** (Selenium / Playwright = 5.1x).
- Smallest gap: **Filter: Completed** (1.8x).
- Warm DOMContentLoaded measured inside the browser: 52.5 ms (Selenium) vs 12.0 ms (Playwright) - different.
- Differences in the operations come from the tools, not from the app: Selenium sends one HTTP WebDriver command per find/click/read and polls its explicit waits, while Playwright keeps one WebSocket connection open and waits with built-in auto-waiting.
