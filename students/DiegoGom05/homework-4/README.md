# Homework 4: Black Box Testing - SecureBank System

## Description

Comprehensive black box test suite for an online banking system simulation (`bankingSystem.js`). The project implements and validates transaction limits, dynamic account fee structures, bill payment validations, and lifecycle state management (`Active`, `Suspended`, `Frozen`, `Closed`) using four fundamental black-box testing techniques:

- **Equivalence Partitioning (EP)**
- **Boundary Value Analysis (BVA)**
- **Decision Tables (DT)**
- **State Transition Testing (ST)**

The test suite is built in JavaScript using Node.js and Jest, achieving 100% statement, branch, line, and function coverage across all modules.

---

## Prerequisites

- **Node.js**: `v22.0.0` or higher
- **npm**: `v10.0.0` or higher
- **Jest**: `v29.7.0` (included in `package.json`)

---

## Installation

Clone the repository, navigate to the project directory, and install the required dependencies:

```bash
cd homework-4
npm install
```
