# Error

## Proceso
La verdad, cometí un error muy simple: desde el navegador modifiqué la misma línea que en el local, por lo cual, cuando traté de hacer `git push` para subirlo a la nube, no me dejó por estar una versión atrás. Para solucionarlo, tuve que hacer `git fetch` y después `status` para tenerlo actualizado, luego `git pull` para traerme los cambios de la rama y, finalmente, corregir, `git add`, `git commit` y `git push`.
