# Homework 2: Testing Concepts Analysis

**Student**: Frijol
**Application**: Canvas (LMS)
**Date**: September 7, 2026

## Summary

Este trabajo analiza las necesidades de testing de Canvas, un sistema
de gestión de aprendizaje (LMS) usado por escuelas. Se identificaron 8
tipos de prueba, se diseñó una estrategia para los 4 niveles de
testing, se aplicaron los 7 principios fundamentales de testing, y se
realizó un análisis de riesgo priorizando las áreas más críticas:
control de acceso por roles, confiabilidad durante exámenes y
entregas, y rendimiento bajo carga.
