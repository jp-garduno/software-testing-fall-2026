## Summary

This submission defines a risk-based test strategy for FoodHub, a hypothetical food-delivery platform that connects customers, restaurants, and couriers. It combines functional and non-functional testing with four testing levels, the seven fundamental testing principles, and a prioritized risk matrix.

The strategy protects the critical customer journey—finding a restaurant, building an order, paying, and receiving accurate delivery status—while also addressing security, accessibility, performance, and operational reliability. Each document provides concrete scenarios, measurable targets, and a rationale for the selected priority.
