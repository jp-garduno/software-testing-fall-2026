# Personal Portfolio

This is a simple personal portfolio created to practice the Git and GitHub workflow.

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## Git Workflow

The project was developed using feature branches. Each feature was developed separately and merged into the main branch through pull requests.

### Branches

- feature/initial-structure
- feature/add-styling
- feature/add-content

## Commit Convention

The project uses conventional commit messages such as:

- feat: new functionality
- style: styling changes
- docs: documentation changes
- fix: bug fixes

## Setup

Clone the repository:

git clone https://github.com/TU-USUARIO/git-workflow-practice.git

Open the project folder and open index.html in a web browser.

## Lessons Learned

This project helped me understand how branches, commits and pull requests can be used to organize changes before merging them into the main branch.
