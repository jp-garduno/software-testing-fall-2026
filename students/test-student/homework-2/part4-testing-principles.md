# Part 4: Testing Principles Application

## 1. Testing Shows Presence of Defects

**Application to FitTrack**:
Testing will help us find bugs but can't prove there are no bugs.

**Impact on Strategy**:

- Test important features first
- Keep monitoring after release

---

## 2. Exhaustive Testing is Impossible

**Application to FitTrack**:
We can't test everything so we focus on critical paths.

**Impact on Strategy**:

- Prioritize high-risk areas
- Use risk-based testing

---

## 3. Early Testing

**Application to FitTrack**:
Start testing early in development.

**Impact on Strategy**:

- Test during development
- Fix bugs early
