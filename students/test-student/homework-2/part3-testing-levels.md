# Part 3: Testing Levels Strategy

## Unit Testing

**Scope**: Individual functions

**What to Test**:

- Login function
- Workout calculation

**Tools**: Jest

**Coverage Goal**: 70%

**Example Test Cases**:

1. Test login with valid credentials
2. Test workout calculation

**Estimated Number of Tests**: ~50 tests

---

## Integration Testing

**Scope**: Multiple components together

**What to Test**:

- Database connection
- API integration

**Tools**: Postman

**Example Test Cases**:

1. Test API calls
2. Test data saving

**Estimated Number of Tests**: ~20 tests
