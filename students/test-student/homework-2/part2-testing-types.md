# Part 2: Testing Types Classification

## Test Type: Functional Testing

**Category**: Functional

**Purpose**: Make sure features work.

**Examples**:

1. User can log in
2. User can add workout
3. User can view history

**Priority**: High

**Justification**: Main features need to work.

---

## Test Type: Performance Testing

**Category**: Non-Functional

**Purpose**: Check app speed.

**Examples**:

1. App loads fast
2. Data syncs quickly

**Priority**: Medium

---

## Test Type: Security Testing

**Category**: Non-Functional

**Purpose**: Keep user data safe.

**Examples**:

1. Password is encrypted
2. API is secure

**Priority**: High

---

## Test Type: Usability Testing

**Category**: Non-Functional

**Purpose**: Make sure app is easy to use.

**Examples**:

1. Navigation is clear
2. Buttons are visible

**Priority**: Medium
