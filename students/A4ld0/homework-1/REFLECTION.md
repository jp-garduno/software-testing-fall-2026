# Reflection

During this homework, I practiced using Git as part of a complete development workflow. One challenge I faced was understanding the difference between the homework branch and the submission folder. At first, it was confusing to know when I should create a branch and when I should create a directory, but after practicing the commands, the workflow became clearer.

The Git commands I found most useful were `git checkout -b`, `git status`, `git add`, `git commit`, and `git merge`. These commands helped me create feature branches, track my changes, save progress in meaningful commits, and combine completed work back into my main homework branch.

For this assignment, I created multiple branches, including `feature/initial-structure`, `feature/add-styling`, and `feature/add-content`. Each branch focused on a specific part of the project, which made the work easier to organize. I also practiced writing commit messages using prefixes such as `feat:`, `style:`, and `docs:`.

I will apply this workflow in the team project by creating branches for specific tasks, making small commits, and using pull requests to review changes before merging. This will help the team avoid confusion, track progress, and work together more effectively.
