# Homework 2: Testing Concepts Analysis

**Student**: David Eduardo Páez Aguilar
**Application**: Spotify
**Date**: 9/7/2026

## Summary

This project analyzes Spotify's testing needs across its core 
listener and artist workflows, defining a strategy that combines 
functional testing with performance, security, load, 
compatibility, usability, and accessibility testing. The strategy 
applies all four testing levels (unit, integration, system, and 
acceptance) and the seven fundamental testing principles to 
prioritize effort toward the highest-risk areas: authentication, 
audio playback, search, and peak-load infrastructure. A risk-based 
test plan ensures that critical failure points — such as 
service outages during peak traffic or unauthorized access to 
user data — receive the deepest and earliest testing 
coverage.
