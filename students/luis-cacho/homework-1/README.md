# Portafolio Personal - Práctica de Git Workflow

Este es un proyecto sencillo creado para demostrar el dominio del flujo de trabajo con Git y GitHub, manejando múltiples ramas, commits semánticos y Pull Requests.

## 🛠️ Tecnologías Usadas
* HTML5
* CSS3
* Git & GitHub

## 🌿 Documentación del flujo de trabajo de Git
Durante este proyecto se utilizó un flujo de trabajo basado en ramas (Feature Branch Workflow). Nunca se trabajó directamente sobre `main`.

**Ramas creadas:**
1. `feature/initial-structure`: Para la creación de los archivos base (HTML, gitignore y README).
2. `feature/add-styling`: Enfocada exclusivamente en agregar CSS y diseño.
3. `feature/add-content`: Para llenar de contenido la página y solucionar bugs menores.

**Convención de Commits:**
Se utilizó la convención de *Conventional Commits*:
* `feat:` para nuevas características.
* `docs:` para cambios en la documentación.
* `style:` para formatos que no afectan la lógica.
* `fix:` para solución de errores.
* `refactor:` para reestructuración de código.

## 🚀 Instrucciones de Instalación
Para correr este proyecto en tu máquina local:
1. Clona el repositorio: `git clone <url-del-repositorio>`
2. Navega a la carpeta: `cd homework-1`
3. Abre el archivo `index.html` en cualquier navegador web.
