## 🎯 Learning Objectives

By the end of this module, you will be able to:
- Create and manage Git repositories
- Make commits with meaningful messages
- Create and merge branches
- Collaborate using pull requests
- Resolve merge conflicts
- Apply Git best practices in team environments

## ❓ Common Questions

**Q: I made a mistake in my commit. How do I fix it?**
A: See [theory/04-commits.md](./theory/04-commits.md) section on `git commit --amend`.

**Q: I accidentally committed to main instead of a feature branch. What do I do?**
A: See [theory/10-best-practices.md](./theory/10-best-practices.md) section on fixing mistakes.

**Q: How often should I commit?**
A: Commit whenever you complete a logical unit of work. See best practices document.

**Q: What's the difference between merge and rebase?**
A: See [theory/06-merging.md](./theory/06-merging.md) for detailed comparison.
