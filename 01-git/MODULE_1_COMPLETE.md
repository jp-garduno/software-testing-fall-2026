## 💡 Usage Tips

### For Instructors

1. **Week 1**: Focus on making students comfortable with basic Git
   - Share theory docs 01-03
   - Have them complete Exercise 01
   - Answer questions in discussion forum

2. **Week 2**: Introduce branching and collaboration
   - Share theory docs 04-06
   - Assign Exercises 02-03
   - Monitor homework progress

3. **Week 3**: Advanced topics and best practices
   - Share remaining theory docs
   - Assign Exercises 04-05
   - Prepare for in-person sessions

4. **Week 4+**: Reinforce through practice
   - Use Git for all submissions
   - Require pull requests for homework
   - Provide feedback on Git usage

### For Students

1. **Don't rush**: Take time to understand each concept
2. **Practice daily**: Use Git for all your work
3. **Make mistakes**: Git is forgiving, experiment!
4. **Ask questions**: Use discussions, office hours
5. **Help others**: Teaching reinforces learning
