# Scenario 3: Shipping Cost Calculator — Solución (Boundary Value Analysis)

## Supuestos de negocio (donde el enunciado era ambiguo)

Antes de las tablas y el código, dejo explícitas las decisiones tomadas, porque en BVA los supuestos
cambian los valores esperados:

1. **Orden de cálculo del costo**: `costo = (tarifa_base_por_peso × multiplicador_de_zona) + recargo_oversized`.
   El recargo de oversized ($20) es un monto plano y **no** se multiplica por la zona.
2. **Peso**: se redondea a 1 decimal (round-half-up) antes de clasificarlo en un tier. Peso `<= 0` → error de validación.
3. **Dimensiones**: deben ser números enteros positivos (`> 0`). Si no son enteras o son `<= 0` → error de validación.
4. **Zona**: solo se aceptan `1, 2, 3, 4`. Cualquier otro valor → error de validación.
5. Si hay un error bloqueante (peso inválido, dimensión inválida, zona inválida o "Not Shippable"),
   la función devuelve `cost = 0.00` y reporta el/los error(es) en la lista `errors`.

## Parte B: Implementación

```python
from decimal import Decimal, ROUND_HALF_UP, InvalidOperation

ZONE_MULTIPLIERS = {
    1: Decimal("1.0"),
    2: Decimal("1.5"),
    3: Decimal("2.0"),
    4: Decimal("3.0"),
}


def _round_money(value: Decimal) -> float:
    return float(value.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))


def calculate_shipping(weight, length, width, height, zone):
    """
    Calculate shipping cost.
    Returns: (cost: float, category: str, errors: list)
    """
    errors = []

    # ---------- Zona ----------
    zone_multiplier = ZONE_MULTIPLIERS.get(zone)
    if zone_multiplier is None:
        errors.append(f"Zona invalida: {zone}. Debe ser 1, 2, 3 o 4.")

    # ---------- Peso (se redondea a 1 decimal) ----------
    weight_value = None
    if weight is None:
        errors.append("El peso es obligatorio.")
    else:
        try:
            weight_value = Decimal(str(weight)).quantize(Decimal("0.1"), rounding=ROUND_HALF_UP)
        except InvalidOperation:
            errors.append(f"Peso invalido: {weight}.")
        else:
            if weight_value <= 0:
                errors.append(f"El peso debe ser mayor que 0 (recibido {weight_value}).")
                weight_value = None

    # ---------- Dimensiones (enteros positivos) ----------
    dims_ok = True
    dims_named = {"length": length, "width": width, "height": height}
    for name, value in dims_named.items():
        if value is None or value != int(value):
            errors.append(f"{name} debe ser un numero entero (recibido {value}).")
            dims_ok = False
        elif value <= 0:
            errors.append(f"{name} debe ser mayor que 0 (recibido {value}).")
            dims_ok = False

    dim_sum = int(length) + int(width) + int(height) if dims_ok else None

    # ---------- Categoria por dimensiones ----------
    dim_category = None
    oversized_fee = Decimal("0.00")
    if dim_sum is not None:
        if dim_sum <= 62:
            dim_category = "Standard"
        elif dim_sum <= 108:
            dim_category = "Oversized"
            oversized_fee = Decimal("20.00")
        else:
            dim_category = "Not Shippable"
            errors.append(f"Suma de dimensiones {dim_sum} supera 108 in; no es enviable.")

    # ---------- Tier de peso / tarifa base ----------
    base_cost = None
    weight_tier = None
    if weight_value is not None:
        w = weight_value
        if Decimal("0.1") <= w <= Decimal("1.0"):
            base_cost, weight_tier = Decimal("5.00"), "Tier 1 (0.1-1.0 lb)"
        elif Decimal("1.1") <= w <= Decimal("5.0"):
            base_cost, weight_tier = Decimal("10.00"), "Tier 2 (1.1-5.0 lb)"
        elif Decimal("5.1") <= w <= Decimal("20.0"):
            base_cost, weight_tier = Decimal("20.00"), "Tier 3 (5.1-20.0 lb)"
        elif Decimal("20.1") <= w <= Decimal("50.0"):
            base_cost, weight_tier = Decimal("40.00"), "Tier 4 (20.1-50.0 lb)"
        elif Decimal("50.1") <= w <= Decimal("100.0"):
            base_cost, weight_tier = Decimal("75.00"), "Tier 5 (50.1-100.0 lb)"
        else:  # w > 100.0
            over_lbs = w - Decimal("100.0")
            base_cost = Decimal("75.00") + Decimal("1.00") * over_lbs
            weight_tier = "Over 100 lb"

    # ---------- Costo final ----------
    if (
        base_cost is not None
        and dim_category is not None
        and dim_category != "Not Shippable"
        and zone_multiplier is not None
    ):
        total = base_cost * zone_multiplier + oversized_fee
        cost = _round_money(total)
        category = f"{weight_tier} - {dim_category} - Zone {zone}"
    else:
        cost = 0.00
        category = dim_category or "Invalid"

    return (cost, category, errors)
```

**Por qué `Decimal` y no `float` directamente:** los cálculos de dinero con `float` acumulan errores de
representación binaria (ej. `0.1 + 0.2 != 0.3`). Usar `Decimal` para el peso y el costo evita que un
redondeo de precisión (`1.15 → 1.2`) o una multiplicación por zona produzcan valores como `10.000000000000002`
en vez de `10.00`.

## Resumen de cobertura de límites

| Categoría     | Límites cubiertos                                                                                                                                                    |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Peso          | min/max de cada uno de los 5 tiers + fórmula por exceso + inválidos (0, negativo) + precisión (redondeo que cambia de tier y redondeo que cae por debajo del mínimo) |
| Dimensiones   | Standard max (62), Oversized min/max (63/108), Not Shippable min (109), inválidas (0, negativa, no entera)                                                           |
| Zona          | Las 4 zonas válidas + zona inválida                                                                                                                                  |
| Combinaciones | Extremos válidos combinados, un caso "Not Shippable" con peso en fórmula por exceso, y un caso con múltiples errores simultáneos                                     |
