### How to Submit Homework

1. **Complete the work** in a feature branch
2. **Create a Pull Request** on GitHub
3. **Wait 2-5 minutes** for automated grading
4. **Review your grade** in PR comments
5. **Submit PR URL** to Canvas

## 🎯 Learning Objectives

By the end of Week 3, you should be able to:

### Git (Module 1)

- ✅ Use basic Git commands
- ✅ Create and merge branches
- ✅ Resolve merge conflicts
- ✅ Create pull requests
- ✅ Follow Git workflows

### Testing Concepts (Module 2)

- ✅ Explain different testing types
- ✅ Understand the testing pyramid
- ✅ Apply the 7 ISTQB testing principles
- ✅ Analyze testing needs for different applications

### Static Testing (Module 3)

- ✅ Write conventional commit messages
- ✅ Configure pre-commit hooks
- ✅ Use linting tools (Pylint, ESLint)
- ✅ Format code with Black and Prettier
- ✅ Fix common code quality issues

## 💡 Study Tips

1. **Follow the order** - Sessions build on each other
2. **Do the exercises** - Hands-on practice is essential
3. **Start homework early** - Don't wait until the last day
4. **Use the discussion board** - Others have similar questions
5. **Take notes** - Summarize key concepts in your own words
6. **Practice in your own projects** - Apply what you learn

---

## ⏰ Time Management

**Recommended Schedule**:

```
Monday:     Session of the week (4 hours)
Wednesday:  Second session or continue first (3-4 hours)
Weekend:    Work on homework (3-4 hours)
```

**Total per week**: ~10-11 hours

**Pace yourself!** Don't try to do everything in one day.
