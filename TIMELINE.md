# Course Timeline - Fall 2026

## Overview

- **Total Duration**: 16 weeks
- **Sessions per Week**: 2 (Monday & Wednesday or Tuesday & Thursday)
- **Hours per Session**: 2
- **Total Contact Hours**: 64 hours
- **Format**: Weeks 1-3 async/offline, Weeks 4-16 in-person

---

## 📅 Weekly Schedule

### **Weeks 1-3: Async/Offline Learning** (6 sessions)

#### **Week 1: Git Fundamentals**

- **Session 1**: Git basics, cloning, commits, branches
- **Session 2**: Merging, pull requests, conflict resolution
- **Materials**: Video tutorials, interactive Git exercises
- **Homework 1**: Due end of Week 2 - Git workflow practice

#### **Week 2: Software Testing Concepts**

- **Session 1**: Introduction to testing, testing types
- **Session 2**: Testing levels, testing principles
- **Materials**: Readings, concept maps, quiz
- **Homework 2**: Due end of Week 3 - Testing concepts analysis

#### **Week 3: Static Testing**

- **Session 1**: Conventional commits, pre-commit hooks setup
- **Session 2**: Linting (Pylint, ESLint), static analysis
- **Materials**: Configuration tutorials, hands-on setup guide
- **Homework 3**: Due end of Week 4 - Configure static testing for a project

---

### **Weeks 4-6: Black Box Testing** (6 sessions)

#### **Week 4: Test Case Design & Equivalence Partitioning**

- **Session 1**: How to design effective test cases
- **Session 2**: Equivalence partitioning technique
- **Homework 4**: Due end of Week 5 - Design test cases using EP

#### **Week 5: Boundary Value Analysis & Decision Tables**

- **Session 1**: Boundary value analysis technique
- **Session 2**: Decision tables and test design
- **Practice**: In-class exercises with real scenarios

#### **Week 6: State Transition & Exam 1**

- **Session 1**: State transition testing technique
- **Session 2**: **EXAM 1** - Practical exam covering Modules 1-3
  - Git operations (30%)
  - Testing concepts application (30%)
  - Static testing setup and configuration (40%)
  - Duration: Full 2-hour session

---

### **Weeks 7-9: White Box Testing** (6 sessions)

#### **Week 7: Coverage Fundamentals**

- **Session 1**: Statement coverage, branch coverage
- **Session 2**: Path coverage, calculating coverage
- **Materials**: Code examples in Python and JavaScript
- **Homework 5**: Due end of Week 8 - Write tests achieving 100% coverage

#### **Week 8: Code Coverage Tools**

- **Session 1**: Coverage.py for Python, NYC/Istanbul for JavaScript
- **Session 2**: Reading coverage reports, identifying gaps
- **Practice**: Generate and analyze coverage reports

#### **Week 9: Mock-up Testing**

- **Session 1**: Introduction to mocking, when to use mocks
- **Session 2**: Mocking frameworks (unittest.mock, Jest mocks)
- **Homework 6**: Due end of Week 10 - Write tests using mocks

---

### **Weeks 10-11: Test Driven Development** (4 sessions)

#### **Week 10: TDD Fundamentals**

- **Session 1**: TDD cycle (Red-Green-Refactor), getting started
- **Session 2**: Writing clean tests, TDD best practices
- **Materials**: TDD Manifesto PDFs, live coding demos
- **Homework 7**: Due end of Week 11 - Develop feature using TDD

#### **Week 11: TDD Practice & Exam 2**

- **Session 1**: TDD exercises, pair programming practice
- **Session 2**: **EXAM 2** - Practical exam covering Modules 4-6
  - Black box test design (30%)
  - White box testing with coverage (40%)
  - TDD implementation (30%)
  - Duration: Full 2-hour session

---

### **Week 12: Data Driven Testing** (2 sessions)

#### **Week 12: Parameterized Tests & Data Management**

- **Session 1**: Parameterized tests (pytest.mark.parametrize, Jest each)
- **Session 2**: Test data management, CSV/JSON data files
- **Materials**: Examples with multiple data sources
- **Homework 8**: Due end of Week 13 - Create data-driven test suite

---

### **Weeks 13-15: System Level Testing** (6 sessions)

#### **Week 13: Behavior Driven Development**

- **Session 1**: BDD introduction, Gherkin syntax
- **Session 2**: Behave (Python) and Cucumber/Jest (JavaScript)
- **Practice**: Write feature files and step definitions

#### **Week 14: Selenium & Web Testing**

- **Session 1**: Selenium WebDriver basics, locators
- **Session 2**: Page Object Model, test automation patterns
- **Homework 9**: Due end of Week 15 - Automate web application tests

#### **Week 15: Playwright & Advanced E2E**

- **Session 1**: Playwright introduction, advantages over Selenium
- **Session 2**: Advanced E2E patterns, CI/CD integration
- **Practice**: Migrate tests from Selenium to Playwright

---

### **Week 16: Performance Testing & Final Exam** (2 sessions)

#### **Week 16: Performance Testing & Wrap-up**

- **Session 1**: JMeter basics, load testing, stress testing
- **Session 2**: **EXAM 3** - Comprehensive practical exam
  - System-level testing (BDD, Selenium/Playwright) (50%)
  - Performance testing with JMeter (25%)
  - Integration challenge (25%)
  - Duration: Full 2-hour session

## 🎓 Tips for Success

1. **Stay on schedule** - The async weeks (1-3) set the foundation. Don't fall behind.
2. **Practice regularly** - Testing is a hands-on skill. Code every day.
3. **Use Copilot wisely** - Let it help, but understand what it generates.
4. **Collaborate actively** - Your team project is 20% of your grade.
5. **Prepare for practical exams** - You'll write real code, not answer multiple choice.
6. **Ask questions early** - Don't wait until the exam to clarify concepts.
