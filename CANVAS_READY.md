## 🚀 Quick Start Guide

### Step 1: Create GitHub Repository (5 minutes)

1. Go to GitHub: https://github.com/new
2. Repository name: `software-testing-fall-2026`
3. Description: "Software Testing Course - Fall 2026"
4. Public or Private: **Public** (so students can clone)
5. **Don't** initialize with README (we already have one)
6. Create repository

### Step 2: Push Local Repository to GitHub (2 minutes)

```bash
cd c:/tmp/software-testing-fall-2026
git init
git add .
git commit -m "chore: initial course setup with modules 1-3 complete"
git branch -M main
git remote add origin https://github.com/jp-garduno/software-testing-fall-2026.git
git push -u origin main
```

### Step 3: Set Up Canvas (60 minutes)

Follow the checklist in: `docs/instructor/CANVAS_QUICK_CHECKLIST.md`

**Quick summary**:
1. Create 6 Canvas modules (copy instructions from CANVAS_ASYNC_INSTRUCTIONS.md)
2. Create 3 homework assignments (instructions provided)
3. Post welcome announcement (copy-paste ready)
4. Set up gradebook categories

### Step 4: Test Everything (20 minutes)

1. Click all GitHub links in Canvas
2. Clone the repository yourself
3. Try submitting a test homework
4. Verify automated grading works
